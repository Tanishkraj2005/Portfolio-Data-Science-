## 🌟 About This Project
This repository contains the source code for my personal portfolio website. It acts as a digital resume and highlights my skills, educational background, latest projects, and certifications. Designed with a clean, modern aesthetic, the portfolio showcases my capabilities as a Data Analyst proficient in SQL, Python, Excel, and Power BI.

## 🚀 Key Features
- **Responsive Design**: fully adapted for desktops, tablets, and smartphones.
- **Dynamic Animations**: features smooth scrolling and dynamic section reveals using `ScrollReveal.js` and `Typed.js`.
- **Live LeetCode Stats**: custom API integration fetching my real-time LeetCode problem-solving statistics and rank.
- **Interactive UI Components**: tabed interfaces for Certificates vs Achievements, and sticky navigation.
- **Project Showcase**: A dedicated section to display web projects and data analysis work.

## 🛠️ Built With
- **HTML5**: Semantic tags for logical structure.
- **CSS3**: Custom styling, CSS Grid, Flexbox, and complex animations.
- **JavaScript (Vanilla)**: DOM manipulation, event handling, and real-time LeetCode API data fetching.
- **External Libraries**: `ScrollReveal.js`, `Typed.js`, `Boxicons`.

## 💻 How to Run Locally

You can run this project locally on your machine with a few simple steps.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Tanishkraj2005/Portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Portfolio
   ```

3. **Open the `index.html` file in your browser:**
   Simply double-click `index.html` or use a local server extension like **Live Server** in VS Code for live reloading.
